# PSkill Whitepaper

PSkill (Portable / Procedural Skill) is an executable skill-package specification for AI runtimes. A PSkill defines its inputs, environment, version-locked resources, execution steps, validation, human participation where required, and explicit failure behavior.

**Status:** Draft / Request for Comment  
**Current specification:** 0.4.0-draft

## 中文说明

PSkill 是面向 AI 运行环境的可执行 Skill 数据包规范。它定义输入、环境、锁定版本的资源、执行步骤、验证、必要时的人工参与，以及明确的失败语义。
